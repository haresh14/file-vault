Support

Keepshire for iPhone and iPad, iOS 18.5 or later. Email hello@haresh.dev.

Forgotten passcode or password

There is no reset, iCloud recovery, or back door. If you forget the real vault credential, the files stay unreadable. Reinstalling Keepshire starts a new empty vault; it does not unlock the old one.

Unlock and Face ID

  • Cancel Face ID / Touch ID to type the vault passcode or password.
  • After three failed biometric attempts, wait 30 seconds, then try again or use the vault credential.
  • Keepshire never asks for the iPhone passcode as the vault password.

Web Upload certificate warning

The browser warning is expected. The phone creates a new certificate each time you start the server. In Safari, use Show Details and visit the site; in Chrome, use Advanced and proceed. In Keepshire, compare the SHA-256 fingerprint if you want to confirm it is this device. You must be on the same Wi‑Fi. Keep the app open while files transfer. If the iPhone is locked, unlock it and retry.

Pairing and downloads

Enter the 6-digit code shown in the app. After five wrong guesses the code locks until you restart the server. Downloads stay off until you allow an export session with Face ID / Touch ID or the vault credential.

Notifications

Permission is requested when you start Web Upload. If you previously refused, open iOS Settings → Keepshire → Notifications, or tap the in-app banner that links there.

Decoy credential

The fake passcode or password opens an empty UI so someone watching the phone can be shown an unused app. It does not create a second encrypted vault and does not hide files from a backup or a filesystem copy.

Contact

Email hello@haresh.dev with your iOS version and what you were doing. Do not send vault files, passcodes, pairing codes, or certificate fingerprints in email.
