Privacy Policy

Effective 17 September 2026. Keepshire is an iOS app by Haresh. Contact: hello@haresh.dev.

What Keepshire is

Keepshire is a local encrypted vault for photos, videos, audio, documents, and other files you import. It has no user account and no cloud sync.

Data we do not collect

Keepshire does not create an account, run analytics, show ads, track you across apps or websites, or sell data. There is no remote service for vault contents.

What stays on your device

Imported files, encrypted metadata, vault credentials, Face ID / Touch ID decisions, security settings, and optional trash contents remain on the device. Vault directories and the app’s Core Data store are excluded from iCloud and computer backup.

The encryption key is derived from your vault passcode or password. Keychain items use This Device Only accessibility and do not sync with iCloud Keychain.

Face ID and Touch ID

If you turn biometrics on, iOS evaluates Face ID or Touch ID on the device. Keepshire does not receive biometric templates or images of your face or fingerprint.

Notifications

Keepshire asks for notification permission when you start Web Upload, so it can tell you when a transfer finishes while the app is in the background. You can refuse. In-app banners still work.

Local network (Web Upload)

Web Upload is optional. When you start it, Keepshire listens on your local Wi‑Fi with HTTPS and a certificate created on the phone. Browsers show a trust warning because there is no public certificate authority. Compare the fingerprint shown in the app if you want to confirm the connection is this phone.

A paired browser can upload files. Downloads require an export session you unlock with Face ID / Touch ID or the vault credential. Files are encrypted after they arrive on the device. Anyone on the same network who obtains the pairing code during a session could reach the server; stop the server when you are done.

Screenshots, recordings, and the decoy credential

Screenshot blanking and the decoy (fake) credential are interface protections. They can hide the vault from someone looking at the screen. They do not protect against a compromised device, a backup, or someone who can read the filesystem.

App Store and this website

This site is static marketing and policy pages. It does not receive vault files. If you email support, that message is handled as ordinary email.

Children

Keepshire does not target children and does not collect personal data for a profile.

Changes

If this policy changes, the date at the top of this page is updated and the new text is published here. Questions: hello@haresh.dev.
